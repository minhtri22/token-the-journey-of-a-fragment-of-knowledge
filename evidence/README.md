# Evidence provenance

This directory will document the provenance of measured examples used in the book.

The book repository is **not** a duplicate research-lineage repository. Canonical experimental evidence remains in the research repositories where it was produced. This index will link each measured example to its canonical source, experiment, frozen artifact, or lineage entry when the commercial editorial audit formalizes those mappings.

Principle:

> Research evidence is referenced here; it is not silently copied and allowed to drift.
